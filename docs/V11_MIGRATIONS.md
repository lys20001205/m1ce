# V11 intentional contract migrations

The V10 recovery, channel, reachable long-consist rescue deadline, warning lead, bounded relief, serialization, real-input, pause/lifecycle, cashout and camera regressions remain in the test suites.

## V11-B
Initial and subsequent departure now require Route -> Car -> Start. Prior tests enter the same public choice methods/UI before exercising the unchanged V10 core. Three gate angles are checked on real rendered meshes in Chromium and WebKit.

## V11-C
The four-second consumable boost is superseded by the frozen sustained STOP/SLOW/CRUISE/FAST contract. Its old test is replaced by sustained speed, exact integration ratios, finite battery consumption, depletion fallback, console permission and global emergency stop tests. Four-/six-second environmental warnings remain tested against route-specific SSOT markers. Industrial no longer includes the Tunnel route's clearance event; the clearance regression selects Tunnel explicitly. These are product contract changes, not lowered gates.

Scenery is now one continuous selected ring, with persistent landmark identities, shared primitive batches, LOD, culling and perspective parallax. The local tangent track stabilizes a straight cutaway consist; distant rails and all landmarks use the ring frame. Browser proof combines mesh world coordinates, projected displacement and actual canvas pixel differences. Frame metrics are measured from raw requestAnimationFrame timestamps, not capped simulation dt or manually stepped test time.

The work-branch staging utility is only a source-transport aid for the constrained editing environment. CI persists generated source only after all current stage tests pass; it cannot deploy or update master. Final release validation will not use a staging utility.
