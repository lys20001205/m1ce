# ROUNDHOUSE V9 asset source policy

V9 gameplay uses procedural/blockout geometry in the browser so the route loop can be tested without external runtime dependencies.

Approved replacement/detail sources for later art passes:

- Kenney Factory Kit — CC0 — https://kenney.nl/assets/factory-kit
- Kenney Prototype Kit — CC0 — https://kenney.nl/assets/prototype-kit
- Kenney Racing Kit — CC0 — https://kenney.nl/assets/racing-kit
- Quaternius asset packs — CC0 — https://quaternius.com/

Rules:

1. Keep route-critical geometry (train cutaway, hatch positions, tunnel clearance, Roundhouse turntable, industrial sweep hazard) authored specifically for ROUNDHOUSE.
2. Use CC0 packs for props, machinery dressing, crates, lamps, pipes and background silhouettes.
3. Do not add assets with unclear or incompatible licenses.
4. Keep source/license references in this file when third-party meshes are actually committed.
